The application icon is an original vector source in `assets/icon.svg`, with PNG/ICO variants generated by the Tauri CLI. No remote images or proprietary artwork are embedded.

Complete available license files are distributed in `licenses/<package>-<version>/` in the release directory. `licenses/packages.json` records each resolved package, its declared license, and copied notice files. Additional dependency metadata can be inspected with `cargo metadata --locked` and installed package manifests. This table does not replace the individual dependency license texts.
