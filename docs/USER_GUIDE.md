# Math Input v0.2 使用手册

## 输入与补全

在目标文本输入框中按 `Ctrl + Alt + M` 呼出 Math Input。数学区域可直接输入数字、字母、运算符、括号；鼠标可点到合法数学位置，左右键沿 MathLive 数学结构精细移动。

输入 `sqrt`、`frac`、`pow`、`sum`、`lim`、`int`、`sin`、`cos`、`tan`、`alpha`、`beta`、`theta`、`pi` 时出现候选菜单。也支持 `genhao / gh`、`fenshu / fs`、`zhishu / zs`、`qiuhe / qh`、`jixian / jx`、`jifen / jf` 等别名。设置中可添加 `sqrt=kg,pfg` 形式的本机别名。

`Ctrl + Space` 随时打开全部命令，也可点击“命令”按钮。上下键只改变高亮候选，不把焦点转移到菜单；继续打字仍输入到数学区域并重新筛选。鼠标单击候选等同于 Enter，Shift 单击等同于 Shift + Enter。

候选现在是光标附近的独立浮层，不参与编辑器或窗口的高度计算。优先向下，空间不足时向上翻转，超长列表内部滚动。在小窗口内可能一次只能看到一至两项，可继续用上下键或滚轮选择。浮层限制在同一 WebView 内，不能显示到主窗口外。

菜单匹配当前编辑分支末尾的最长有效命令后缀。例如已有 `b`，继续输入 `sqrt`，只把 `sqrt` 识别为命令，保留 `b` 作为数学内容。普通变量名与命令可能同名；不想接受候选时按 Esc 关闭菜单。

## 默认值与嵌套

接受模板后，第一个参数的**全部默认内容**被选中。直接打字会替换整个值。`sum` 的默认值按顺序为 `i`、`k`、`k+t`、`x_i`，选择 `k+t` 后输入 `n` 会得到 `n`。

| 按键 | 活跃参数会话内的行为 |
| --- | --- |
| Tab | 保留当前内容，选中下一个参数；最后一个参数后退出模板 |
| Shift + Tab | 返回本模板的上一个参数；首参数处停留 |
| Enter | 保留当前及所有后续默认内容，立即退出当前模板 |

参数提示显示模板路径、参数名称、含义和进度。可点击参数内容精细编辑，当前会话会同步到所点击的参数。

在参数中输入另一个命令会开启内层会话。例如 `frac → sqrt → frac`。内层完成后返回外层当前参数的插入点；再按 Tab 才前进到外层下一参数。父参数不会重新整体选中，因此继续打字不会误删刚完成的内层公式。

Enter 的固定优先级：**输入法组合确认 → 接受补全 → 完成当前模板 → 提交整式**。完成模板的 Enter 不会关闭窗口。某些单字母会匹配命令前缀；如要确认参数本身，可先 Esc 关闭候选，再 Enter，或直接 Tab。

## 智能包裹

补全菜单打开时，Enter 正常插入；Shift + Enter 优先用当前选区填入模板的包裹参数。没有显式选区时，取命令前光标左侧、当前数学分支内的数学项。

| 输入上下文 | 接受 sqrt 的包裹结果 |
| --- | --- |
| `a+b` 的 `b` 后 | `a+\sqrt{b}` |
| `(a+b)` 后 | `\sqrt{(a+b)}` |
| `x²` 整体外部右侧 | `\sqrt{x^2}` |
| 指数 `2` 内部右侧 | `x^{\sqrt{2}}` |
| `abc`、`2x` 后 | 整个隐式乘法项被包裹 |

加减、关系、显式乘除和分隔符形成项边界。连续数字作为数字组处理；这不修改公式本身，也不会机械地插入乘号。多个相邻因子可作为一个操作项。多位数内部的光标只操作其左侧部分，保留光标右侧数字。

若先选中数学内容再输入命令，应用记住刚才的选区，Shift + Enter 使用该选区。若想在不替换选区的情况下选择命令，可在选区存在时按 Ctrl + Space，再选择候选。

## 结构导航与选区

| 按键 | 行为 |
| --- | --- |
| ← / → | MathLive 普通精细移动，可进入子结构 |
| Ctrl + ← / → | 在当前编辑分支中跨过相邻数学项；在运算符旁先跨过单个运算符 |
| Ctrl + Shift + ← / → | 按方向选择相邻数学节点；继续同方向扩大，反方向按历史收缩 |
| Alt + ← / → | 跳到最近数学容器的左/右外部边界；阻止 WebView 历史导航 |
| Alt + Shift + → | 扩展选区：相邻数学原子/整体幂 → 隐式乘法项 → 当前分支 → 父结构 |
| Alt + Shift + ← | 沿本次扩展历史逐步收缩，精确恢复之前的选区或光标 |
| Ctrl + Z / Ctrl + Y | 撤销 / 重做，Ctrl + Shift + Z 也可重做 |
| Ctrl + Backspace / Delete | 删除当前分支中左侧 / 右侧数学项；显式选区优先 |
| Ctrl + M | 在对应括号的内外边界之间跳转 |
| Ctrl + Alt + U | 解除安全的函数、平方根或外层括号，保留内部内容 |

例如分子 `x²+y` 中，在 `x²` 左侧按 Ctrl + →，跨过完整 `x²` 到 `+` 前，不进入指数。在指数内部按 Alt + → 只跳出幂；在分子内按该键跳出分式。每次只处理一个最近容器。

在 `2x²+3y` 的底数 `x` 右侧，Ctrl + Shift + ← 可依次选择 `x`、`x²`、`2x²`、整条同层表达式。反方向逐级返回之前的选区。起始方向决定先选择光标哪一侧，后续按包含关系扩大；在分子内部不会直接选择无关分母。整个分子已选中后，进一步扩大才包含分式。鼠标定位、普通方向键或重新输入会清除扩展历史。原 Alt + Shift + →/← 作为兼容映射保留。

结构选择使用 MathLive 的真实 Selection，强调背景对应实际选中内容，不会添加 `\boxed` 或改变输出。模板参数默认选区仍有自身边框；它和结构选择是两种状态。Esc 先关闭候选，再清除结构选择，最后才取消窗口；普通模板默认选区不会额外拦截 Esc。

## 函数删除、括号与解除结构

已经解析的 `\sin`、`\cos`、`\tan`、`\lim` 等函数命令有原子范围。在函数名称边界按 Backspace/Delete，先选中完整名称；再次删除才删除整体。普通字母 `sin`、`sinValue` 仍按字符编辑，不会因为拼写相似被升级为函数。MathLive 已解析的函数命令本身不能把三个可见字母拆成独立数学字符；需要其他名称时替换该命令或使用普通文字输入。

已选择的结构可用 Backspace/Delete 整体删除，普通输入可替换选区；Ctrl + Space 选择模板后，Shift + Enter 可把选区作为模板参数。每次结构删除和解除结构具有独立撤销边界。连续运算符暂时保留，空分子、空分母和空指数继续由 MathLive 提供可编辑位置，不猜测或合并用户的数学表达式。

普通圆括号、方括号和已识别的 MathLive `\left/\right` 圆/方括号支持配对跳转、整体选择和解除。单侧精细删除保留另一侧，不强制同时删除两边。嵌套、分式或根式内部按同一数学分支匹配；只有一侧、光标不在括号边界或定界符无法确认时，Ctrl + M 安全无操作。花括号的已识别形式可沿用结构投影，但尖括号、绝对值、混合定界符和矩阵尚不承诺同等匹配能力。

点击“解除结构”或按 Ctrl + Alt + U：`sin(x) → x`、`sqrt(x) → x`、`(a+b) → a+b`。无明确单一主体的分式、带根指数的根式、带幂/上下限的函数、未知结构会拒绝解除并保留原文，避免丢掉额外分支。

## 窗口与缩放

默认紧凑模式，界面缩放为 85%。Windows 窗口初始为 420 × 224 逻辑像素，会适配实际内容高度；提示或复杂公式可能需要更高。窗口仍可手动调整。候选列表的出现、筛选和条目变化不触发窗口尺寸调整。

设置中用 65%～125% 滑动条预览数学字体、普通文字、按钮、间距和候选尺寸，点击“保存设置”持久保存。取消会恢复已保存的外观。关闭紧凑模式可显示更多提示文字；紧凑模式依然保留命令、解除结构、输出模式、复制、提交和帮助入口。参数说明可悬停查看，复杂公式可在编辑区滚动，不通过缩放变换伪造点击区域。

## 输出与取消

输出选择器提供行内 `$…$`、块级 `$$` 换行包围、纯 LaTeX。LaTeX 由 MathLive 正规化，再清除编辑用占位标记。MathLive 可能把单字符参数紧凑序列化为 `\frac12`、`\sqrt2`，与带花括号写法等价。

“仅复制”明确用结果替换剪贴板，并保留窗口。“插入公式”尝试回到原输入框并粘贴。关闭自动粘贴后，提交改为复制并隐藏窗口。

自动粘贴要求原进程、生命周期、窗口、焦点句柄和 UI Automation 控件身份均匹配，并且原控件是已启用、非密码的普通 Edit / Document 控件。系统不允许恢复焦点、目标关闭、管理员程序、命令终端或无法识别的控件一律转为手动复制。

临时剪贴板事务只支持纯文本格式，先完整保存原格式字节，写入公式，再发送前台 Ctrl + V。短暂等待后，仅在剪贴板序号仍属于本次写入时恢复。用户或其他程序期间复制的新内容不会被覆盖。图片、文件、HTML/富文本或其他混合格式会阻止自动粘贴并保留原剪贴板。

按键发送成功不保证所有程序都已经完成粘贴，请检查目标应用；生成结果始终保存在“上次生成结果”，可手动选取或复制。草稿与最近生成结果保存在本机 WebView 存储中，不上报。

Esc 在候选打开时先关闭候选；如有结构选择，再次 Esc 清除选择；没有这两种状态时才取消窗口。取消不触碰剪贴板、不发送输入，草稿保留。全局快捷键在编辑器已获焦点时也可收起窗口。托盘菜单可再次打开或完全退出。
