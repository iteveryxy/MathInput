# v0.2 架构与可靠性边界

## 编辑链路

`EditorWindow → MathEditor → CompletionEngine / PlaceholderManager / MathNodeNavigator → MathfieldElement`。

UI 仅显示状态并发出意图。补全引擎是纯筛选与高亮状态，不调用 MathLive。模板注册器存放声明；PlaceholderManager 只通过公开插入与选区 API 操作编辑器。数学结构模块投影公开偏移信息，可用保存的真实偏移表独立测试。输出格式化不依赖 Windows。

| 状态 | Enter | Tab | Esc |
| --- | --- | --- | --- |
| IME composition | 交给输入法，不分发产品快捷键 | 交给输入法 | 交给输入法 |
| 活跃候选 | 插入；Shift 则智能包裹 | 有活跃模板时导航参数 | 关闭候选 |
| 活跃参数会话 | 结束当前一层，保留所有内容 | 同层参数导航 | 取消窗口，保留草稿 |
| 结构选择 | 保持原 Enter/Tab 优先级 | 保持模板导航 | 先折叠结构选区，不取消窗口 |
| 普通编辑 | 提交整式 | 常规 MathLive/界面导航 | 取消窗口 |

普通箭头由 MathLive 接管；候选上下箭头、结构 Ctrl / Alt 快捷键在 capture 阶段明确分流。程序化插入使用静默通知，但真实输入事件始终重新计算补全，兼容没有 ASCII keydown 的文本服务。

v0.2 把 Ctrl + Shift + 方向键映射到 `SelectionManager.extend(direction)`，Alt + 方向键映射到最近容器出口；旧 Alt + Shift 选择映射保留。文档 capture 处理 Alt + 方向键的默认浏览器导航，但不吞掉数学编辑器自己的事件。Ctrl + M 配对跳转，Ctrl + Alt + U 解除单一明确外壳。IME composition 始终先返回，Enter/Tab 原状态机保持不变。

## 结构投影

`getElementInfo()` 返回的后序偏移包含节点深度及当前节点 LaTeX。适配器逐层保留由空哨兵分隔的可编辑分支，把后置上下标与紧邻底数组成操作节点，并合并连续数字。普通括号在同一分支内组合成节点；智能括号本身已有结构分支。

隐式乘法模块**不执行代数解释或改写**，只在同层非边界因子间形成操作范围。加减、关系、显式乘除及分隔符是边界。因此 `23` 是数字组，`2x` 是可一起操作的相邻因子，`sin(x)` 可整体操作。未知复杂数学语义不会被改写成乘法表达式。

v0.2 投影保留幂的底数/脚本组成部分、括号主体及外壳范围；只把明确的函数命令和相邻已配对括号组成调用节点。普通 `sinValue` 不会按子串变为函数。`SemanticEditing` 只生成删除、配对跳转和解除结构计划；`MathEditor` 仍通过公开 Selection、Position、insert 与 executeCommand 执行。多分支分式、带指数的函数和不确定结构不做猜测性 Unwrap。

`SelectionManager` 保存本次方向、原选区与期望内容，反方向回退历史；MathLive 的真实 Selection 同时负责编辑范围和视觉高亮。外部选择变更或内容改变会清理历史。高亮仅为 CSS 自定义属性，不向 LaTeX 写入排版标记。普通输入与非特殊的细删继续交给 MathLive。若公开节点信息缺失，结构操作抛出明确错误，不访问私有对象。

`EditHistoryBoundary` 通过公开的 undo-state-change 事件跟踪最近快照。在细删与结构操作交界处，必要时用公开 insert 提交当前已选内容，再用公开导航命令结束合并；随后一次范围替换完成操作。不会调用私有 UndoManager，也不会让 Undo 选中无关的整个公式。内容撤销由 MathLive 管理，选择扩大/收缩由当前会话历史管理。

升级 MathLive 前必须重新跑 Phase 0、实际偏移探测与全部结构 UI 测试。

## 独立补全与紧凑布局

`CompletionPopup` 作为 body 下的 fixed portal；候选的渲染、详情展开和滚动不会改变 shell 的尺寸。`CaretAnchor` 只读取公开 `getElementInfo(offset).bounds`，在脚本偏移没有边界时回退到附近公开元素；这是数学光标附近的近似位置，不依赖 Shadow DOM。`FloatingPosition` 是纯几何函数，按可用 CSS 视口向下/向上放置，并限制宽高。

输入/选择后、字段 ResizeObserver、滚动、窗口与 visualViewport 变化都会在下一帧重新定位。浮层 pointerdown 阻止焦点转移，点击仍经原补全接受入口。所有坐标均为同一 WebView 的 CSS 像素，避免把系统物理像素与页面缩放混用。它不能跨出 WebView 边界，超长候选内部滚动；不创建额外原生窗口。

根字号由 `--ui-scale` 控制，其余组件使用 rem，设置范围 65%～125%。不使用 transform: scale。原本地设置键继续使用 v1，旧数据只补 uiScale/compact 默认值，不重置快捷键、别名、草稿或上次结果。默认紧凑界面保留固定参数提示行，长公式在编辑容器内滚动；`revealCaret()` 使用公开边界调整该容器滚动，不移动整个页面。

原生窗口仍根据 shell 内容变化适配高度，但 portal 不计入 shell。设置/帮助可增长窗口，候选不增长窗口。手动宽度调整仍使用 Tauri 已有能力。

## 模板与撤销

每个模板实例有独立锚点及参数 ID。会话栈保存父参数索引，内层持有 Tab/Enter，完成后弹栈。完成时一次插入展开当前锚点中的真实内容，移除已完成的元数据，父模板其他参数身份不变。

MathLive 负责实际撤销栈。应用用有界的 200 个正文快照保存会话状态，在 Ctrl + Z/Y 时恢复；任何已不存在的锚点都会清理对应会话。完成模板是一项可撤销操作。极长撤销历史超过会话缓存后，内容仍由 MathLive 撤销，但不能保证恢复过旧的参数填写会话。

## Windows 边界

原生桥是一个串行后台线程，统一持有 COM/UI Automation 状态与剪贴板事务。WebView 不接收任意系统 HWND 或键码参数。可调用命令只有查询状态、配置快捷键、提交、显式复制和取消。

全局快捷键释放时记录原前台窗口、原焦点句柄、进程 ID、进程创建时间与 UIA 元素身份。只读检查控件类型、是否密码、是否启用、是否有焦点；不读取目标控件的 Value 或用户原文。呼出时分别聚焦顶层窗口、嵌入 WebView，再聚焦 MathLive。

提交分为两步：

1. **预检**：目标仍存在、处于普通桌面、用户已松开修饰键、剪贴板可完整安全保存。
2. **执行**：隐藏本窗口，尝试 `SetForegroundWindow`，重新确认窗口和 UIA 元素；仅向已核验前台发送一次 Ctrl + V。没有后台 `PostMessage`、`AttachThreadInput`、提权或安全桌面绕过。

每项请求有截止时间。过期排队请求被丢弃；慢 UIA 调用返回后，在任何键盘注入前再次检查期限。失败立即返回手动复制路径，并尽量重新显示编辑器。后台线程失效不影响前端保留的生成结果。

自动临时剪贴板只接受 Windows 纯文本格式（CF_TEXT、CF_OEMTEXT、CF_UNICODETEXT、CF_LOCALE）。先分配所有内存，再写入；恢复时校验剪贴板序列号，防止覆盖期间发生的新复制。富文本、图片、自定义格式采用保守回退。显式“仅复制”代表用户主动用公式替换剪贴板。

`SendInput` 返回接收数量只说明注入请求被接收。应用的状态消息不会把它报告为已验证的跨应用粘贴。实际收到内容的证据必须来自专用测试目标或人工核验。

## 数据与网络

模板和字体来自安装包，前端资源嵌入 EXE。运行时没有账号、遥测或云 API。Tauri 内容安全策略仅允许本地资源和 IPC；不提供远程页面或任意文件/进程启动能力。

快捷键原生配置位于当前用户的 Tauri 应用配置目录。偏好、草稿和上次结果位于同一应用的 WebView 本地存储。写结果发生在隐藏窗口/系统操作之前，取消不清空草稿。关闭窗口隐藏到托盘，退出需要托盘菜单。程序不注册开机启动、不修改系统 PATH、不申请管理员权限。
